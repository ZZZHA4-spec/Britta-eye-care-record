# 术后用药打卡

一个手机优先的静态网页/PWA，用来记录术后滴眼药、生成复诊日期，并导出 iPhone 日历提醒。

## 功能

- 添加和删除药品提醒
- 设置药品名称、开始日期、使用天数、每日次数和具体时间
- 点击今日药品卡片打卡，再点一次取消
- 查看最近 14 天打卡记录
- 输入手术日期，自动生成常见复诊日期
- 导出用药和复诊 `.ics` 日历文件，iPhone 打开后可加入系统日历
- 本地存储，无需登录和服务器

## 本地运行

推荐用本地静态服务打开，PWA 和日历下载行为会更稳定。

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/index.html
```

也可以直接部署到 GitHub Pages、Cloudflare Pages 或任意静态网站服务。

## iPhone 使用建议

1. 用 Safari 打开网页。
2. 点击分享按钮，选择“添加到主屏幕”。
3. 在网页里添加药品和手术日期。
4. 点击“导入提醒”或“导入复诊日历”，打开生成的 `.ics` 文件并加入日历。

注意：本工具只负责提醒和记录，具体用药和复查安排以医生医嘱为准。
